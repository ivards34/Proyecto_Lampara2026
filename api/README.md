# api/ — LamparaApi

API REST (**LamparaApi**) que recibe las mediciones del ESP32, las almacena y las
expone a la app: entrega temperatura/humedad y estado actual (GET), y recibe el
estado/intensidad de la luz (POST).

> **Alcance:** este componente se desarrolla en **otra materia** (no en Aplicaciones
> Móviles). Se incluye aquí para dar contexto al proyecto integral. Pendiente de
> definir el contrato (URL, JSON de cada endpoint) y de volcar código.
