# src/ — Código de la aplicación

Aquí vive el código de la aplicación móvil **LamparaApp** (.NET MAUI).

```text
src/
└── LamparaApp/
    ├── Models/        → entidades (Medicion, EstadoLuz)
    ├── Views/         → pantallas .xaml (Principal, Histórico)
    ├── ViewModels/    → lógica de cada pantalla (MVVM)
    ├── Services/      → acceso a la API (ApiService) y base de datos local
    ├── Resources/     → estilos, colores, imágenes, fuentes
    └── AppShell.xaml  → navegación
```

> El proyecto MAUI se crea al terminar la etapa de ejercicios (`ejercicios/`).
