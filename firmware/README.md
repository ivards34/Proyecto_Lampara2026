# firmware/ — Estación / lámpara (ESP32)

Firmware del microcontrolador **ESP32** que controla el panel LED y lee el sensor
de temperatura y humedad, publicando las mediciones hacia la API.

> **Alcance:** este componente se desarrolla en **otra materia** (no en Aplicaciones
> Móviles). Se incluye aquí para dar contexto al proyecto integral. Pendiente de
> volcar código y documentación.
