# ejercicios/ — Prácticas previas a la app

Antes de desarrollar la app real, cada concepto se practica en un **ejercicio
pequeño y aislado**. Cada uno va en su propia carpeta numerada, con su `README.md`
que explica qué practica y qué se investigó.

El detalle completo de cada ejercicio está en
[`docs/LamparaApp/Ejercicios_Por_Pantalla.md`](../docs/LamparaApp/Ejercicios_Por_Pantalla.md).

## Listado

| Carpeta | Ejercicio |
|---------|-----------|
| `01-mostrar-temp-humedad-estado/` | Mostrar temperatura, humedad y estado en tarjetas |
| `02-get-datos-api/` | GET de datos a la API |
| `03-estados-carga-error/` | Estados de carga y error |
| `04-comparacion-interna-externa/` | Comparar temperatura interna (lámpara) vs externa (clima) |
| `05-selector-estado-4-opciones/` | Selector de estado con 4 opciones |
| `06-slider-intensidad/` | Regulación de intensidad con slider (%) |
| `07-post-estado/` | Enviar el estado con POST |
| `08-color-segun-temperatura/` | Colorear la lámpara según temperatura (celeste → rojo) |
| `09-indicador-conexion/` | Indicador de conexión (heartbeat) |
| `10-selector-fecha/` | Selector de fecha (calendario) |
| `11-grafico-dos-lineas/` | Gráfico de dos líneas con dos escalas |
| `12-vista-horizontal/` | Ver el gráfico en horizontal (landscape) |
| `13-sqlite-historico/` | Tabla local simple (time_day, temperatura, humedad) |
| `14-navegacion/` | Navegación entre Principal e Histórico |
